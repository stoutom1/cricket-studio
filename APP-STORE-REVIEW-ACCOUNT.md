# Cric4All — Apple Review Account Plan

Before App Store submission create a dedicated review-only account.

Do NOT use a personal administrator account.

Recommended review setup:
- Dedicated email/account for Apple App Review.
- One review/test league.
- Two test teams.
- Enough players to start a match.
- One scheduled/in-progress test match.
- Permissions sufficient to open Scoring and record deliveries.
- No production/private league data.

App Store Connect Review Notes should include:
1. Review username/email.
2. Review password.
3. Exact navigation:
   Dashboard -> review league -> Scoring -> review match.
4. How to test native Share.
5. How to enable App Notifications:
   Account menu -> Enable App Notifications.
6. How to test offline scoring if included in the submitted build.
7. Any push test trigger that is genuinely available to the reviewer.

Keep the review account/backend active for the entire review period.
