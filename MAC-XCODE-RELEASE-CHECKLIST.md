# Cric4All — Mac/Xcode Release Checklist

Use this only after VSJ SERV LLC Apple Developer membership is active.

## Xcode
- Use the current Xcode version accepted for App Store submission.
- Open ios/App/App.xcodeproj.
- App target -> Signing & Capabilities.
- Team: VSJ SERV LLC.
- Bundle ID: com.cric4all.app.
- Device family: iPhone.
- Version: 1.0.
- Build: increment for every uploaded archive.

## Push Notifications
Only after the Apple App ID/team is active:
- Add Push Notifications capability.
- Confirm aps-environment entitlement is generated by Xcode/signing.
- Configure the required APNs/provider credentials for Cric4All's push backend.
- Do not manually invent production entitlement values.

## Physical iPhone
Validate:
- fresh install
- sign in/out
- scorer
- offline/resume/reconnect
- background/foreground
- native share sheet
- Account -> Enable App Notifications
- notification permission appears only after button tap
- push opens intended Cric4All route
- account deletion path
- privacy/support/legal links

## TestFlight
- Archive
- Validate
- Upload
- Complete export compliance/privacy metadata
- Install via TestFlight
- repeat physical-iPhone checklist
